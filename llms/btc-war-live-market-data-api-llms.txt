# BTC War

> BTC War is a real-time 3D visualization that turns live Binance Spot order flow for nine selectable crypto markets into any of six independently selectable battlefield simulations.

- Canonical site: https://btcwar.net/
- Entity identity: BTC War means the browser-based crypto market visualization at https://btcwar.net/; it is not WAR coin, a token or geopolitical Bitcoin commentary.
- Source-code status: BTC War's private application source is not published or licensed as open source; the public GitHub repository contains project documentation only.

- Market data: Binance Spot ticker, aggregated trades and periodically refreshed visible order-book depth for BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT, XRPUSDT, TRXUSDT, DOGEUSDT, ZECUSDT and ADAUSDT
- Visualization: buy and sell liquidity are represented as opposing armies
- Battlefields: BTC War, Voxel Siege, Arcane War, Medieval Siege, Space War and Champion Duel
- Supported markets: BTC, ETH, BNB, SOL, XRP, TRON (market code TRX), DOGE, ZEC and ADA spot pairs against USDT
- Selector model: market and battlefield choices are independent, allowing 54 market-and-scene combinations rather than a fixed mapping
- Interaction: users can switch scenes, deploy a battlefield soldier, control audio and inspect a live trade feed
- API access: USD 0; no account, no API key, no registration and no payment required
- Language: English

## Limitations

- BTC War is descriptive and educational. It does not predict crypto prices, provide trading signals, identify traders, expose hidden liquidity, hold funds, execute trades, or provide financial advice.
- The public GitHub repository contains project documentation only. Private application source, deployment configuration, credentials and build artifacts are not published there.
